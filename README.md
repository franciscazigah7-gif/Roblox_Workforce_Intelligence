# Roblox Africa Operations (Ghana Hub) – Workforce Intelligence Dashboard

## 📊 Project Overview
An interactive Power BI HR and operational analytics dashboard designed for Roblox Africa Operations (Ghana Hub). This project evaluates workforce dynamics, headcounts, attrition patterns, and productivity indicators to support data-driven talent planning and retention strategies.

---

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** Data modeling, star schema design, interactive visuals, and cross-filtering
* **DAX:** Formulated measures for attrition rate, average tenure, department-level distribution, and performance KPIs
* **Excel / SQL:** Data extraction, transformation, cleaning, and validation

---

## 🔍 Key Insights & Findings
* **Headcount & Distribution:** Analyzed workforce volume across operational teams to highlight key staffing ratios and departmental allocations.
* **Attrition & Retention Trends:** Pinpointed core drivers behind staff turnover, segmenting patterns by tenure, department, and role level.
* **Productivity Benchmarks:** Correlated team capacity with operational output to guide management on strategic talent allocation.

---

## 🚀 How to Interact with the Dashboard
1. Download the `.pbix` file from this repository: `Roblox_Workforce_Intelligence.pbix`.
2. Open the file in **Power BI Desktop** to explore the interactive slicers, drill-through pages, and DAX calculations.
